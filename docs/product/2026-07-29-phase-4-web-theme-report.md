实机自动化使用专用测试模式：

- `/?test=1` 关闭计时器和行情后台轮询，避免测试请求与页面轮询叠加。
- 设备 HTTP 请求默认最小间隔为 3 秒，可通过 `--request-interval` 调整。
- HTTP 功能回归完成后，再独立执行串口日志断言，避免串口占用干扰局域网测试。
- 串口断言先写入唯一 `log mark`，再通过 `log 100` 读回，防止历史日志造成假通过。

当前阶段按产品要求只判断功能是否打通，不将性能、长期稳定性和网络连续性作为完成门槛。
