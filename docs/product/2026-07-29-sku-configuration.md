# 首批 SKU 配置表

版本：`1.0.0-rc1`  
适用范围：首批不超过 10 台

## SKU

| SKU | 建议首发价 | 硬件 | 固件与功能 | 交付时的固定配置 |
|---|---:|---|---|---|
| 标准版 | 129 元 | ESP32-C3、1.54 英寸 ST7789、固定外壳、USB-C 供电 | 完整表情、AUTO、本地 Web、时钟/天气/行情/番茄钟/开发者状态 | `MOCHI`、`HELLO` / `MOCHI`、Classic Orange、Normal、手动模式 |
| 定制版 | 169 元 | 与标准版相同 | 标准版全部功能 | 在交付前写入昵称、两行开机短句、主题、默认表情；可选 AUTO |

## 共同约束

- 两个 SKU 使用同一份 `1.0.0-rc1` 固件和 LittleFS 产物，不为订单改代码或重编译。
- WiFi 凭据不属于订单配置，不导出、不交付、不留档。
- 昵称为 1–12 个可打印 ASCII 字符；每行开机短句最多 16 个可打印 ASCII 字符，可为空。
- 默认表情只能从设备已支持的 8 种表情中选择；主题只能是 Classic、Dark、Mint、Pink。

## 定制版制作与交付

1. 刷入 RC1 固件及 LittleFS，并确认版本接口或串口 `status` 显示 `1.0.0-rc1`。
2. 在本地 Web 的 Profile、Theme 和 Expression 区域写入订单配置。
3. 导出配置 JSON，作为订单留档；确认文件不含 WiFi 密码和日志。
4. 重启后核对开机短句、主题及默认表情。
5. 交付时仅提供设备、USB-C 线、热点名称和访问地址说明；不交付测试网络凭据。

## 标准版出厂基线

标准版不导入额外 Profile；使用固件默认值：`MOCHI`、`HELLO`、`MOCHI`、Normal、manual。Classic Orange 对应主题 ID `1`。如曾写入测试配置，使用 Web 的 Profile reset 和恢复默认配置后再交付。
